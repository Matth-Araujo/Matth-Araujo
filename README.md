### 👨‍💻 Sobre Mim

Sou desenvolvedor de software apaixonado por construir arquiteturas robustas, sistemas distribuídos de alto desempenho, aplicações web científicas e experiências mobile modernas. Gosto de resolver problemas complexos — desde protocolos **Peer-to-Peer (P2P)** em **Go & gRPC** até plataformas automatizadas de **Modelagem Molecular 3D** em **Python/Django** e aplicações **Flutter**.

- 🔭 **Foco atual:** Desenvolvimento Back-End, Sistemas Distribuídos, Inteligência Artificial e Aplicações Mobile (Flutter).
- 🌱 **Explorando:** Arquiteturas orientadas a microsserviços, comunicação via gRPC/Protocol Buffers, algoritmos de consenso (Gossip) e computação científica.
- ⚡ **Diferencial:** Base sólida em algoritmos, estruturas de dados, programação concorrente e integração entre múltiplas tecnologias.
